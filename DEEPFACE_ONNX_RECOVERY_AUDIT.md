## 1. Executive Summary

A full forensic audit was conducted across `/home/opc/attendance_system`, `/home/opc/attendance_system/rust_deepFace`, `/home/opc/attendance_system/crates/attendance-face`, and git commit history (`00377e4` through `c1af9a7`) to reconstruct how Python `DeepFace.represent(model_name="Facenet512", detector_backend="mtcnn")` in `attendance_v8.py` was migrated to Rust ONNX (`tract-onnx`).

### Critical Root Causes Discovered & Remediated

| Finding ID | Component | Historical Defect Discovered | Root Cause | Remediation Implemented |
| :--- | :--- | :--- | :--- | :--- |
| **DF-01** | `models/*.onnx` vs `rust_deepFace/generate_onnx_models.py` | The 4 ONNX files previously committed to `models/` (`facenet512.onnx` at 1.19 MB, `mtcnn_pnet.onnx` at 3.5 KB, `mtcnn_rnet.onnx` at 422 KB, `mtcnn_onet.onnx` at 1.56 MB) were **not** authentic pretrained weights. They were generated by `rust_deepFace/generate_onnx_models.py` using `np.random.seed(42..45)` random Gaussian tensors, with `facenet512.onnx` replaced by a tiny 3-conv proxy network instead of the 447-layer Inception-ResNet-v1 architecture. | Developer shortcut during initial `rust_deepFace` PoC to satisfy ONNX tensor shapes (`[1,3,160,160] -> [1,512]`) without converting the actual Keras `.h5` / PyTorch `.pt` weights. | Built `scripts/convert_authentic_onnx.py` to convert authentic `serengil/deepface_models` `facenet512_weights.h5` (94,176,340 bytes, 447 layers) and `timesler/facenet-pytorch` `pnet.pt`, `rnet.pt`, `onet.pt` into ONNX opset 13 models in `models/`. |
| **DF-02** | `crates/attendance-face/src/pipeline.rs` (`lines 87-111`) | When MTCNN failed to detect a face (`detect_face` returned `Err`), `extract_face_embedding` caught the error, logged a warning, and silently took a **60% center crop** of the image and passed it to `facenet512.onnx`. | Added to prevent synthetic/random MTCNN weights from failing on test images; caused non-face images (blank, noise, walls) to produce valid 512-D embeddings (`enforce_detection=False` behavior). | Completely removed the 60% center-crop fallback in `crates/attendance-face/src/pipeline.rs`. `mtcnn::detect_face(state, &img)?` now strictly enforces `NoFaceDetected` (HTTP 422) and `MultipleFacesDetected(n)` (HTTP 422). |
| **DF-03** | `crates/attendance-face/src/mtcnn.rs` (`run_onet`) | 1. O-Net 5-point landmarks (`outputs[0]`) were ignored and replaced with hardcoded bounding-box ratios (`x1 + 0.3*w`, etc.).<br>2. `run_onet` lacked post-regression `Min`-NMS (`inter / min(area1, area2)`), causing 5–11 overlapping O-Net boxes to survive on a single face. | Incomplete port of Stage 3 MTCNN in `mtcnn.rs`. | 1. Extracted real O-Net 5-point facial landmarks (`x_j = x1 + w * pts[j]`, `y_j = y1 + h * pts[j+5]`).<br>2. Added post-regression `Min`-NMS (`threshold = 0.7`) at the end of `run_onet` and multi-face prominence check (`detect_faces`). |
| **DF-04** | `facenet-pytorch` `.pt` Legacy Stride Layout | `pnet.pt`, `rnet.pt`, and `onet.pt` use legacy PyTorch pickle storage with column-major (Fortran) strides (`stride=(1, 10, 30, 90)`) and Caffe `[W, H, C]` flattened dense layer ordering. Naive `np.frombuffer().reshape()` scrambles the convolution kernels. | Legacy Caffe-to-PyTorch weight serialization in `facenet-pytorch`. | `scripts/convert_authentic_onnx.py` reconstructs exact strided views via `np.lib.stride_tricks.as_strided` and permutes flattened `[W, H, C]` dense weights to `[C, H, W]` (`NWHC -> NCHW`) before ONNX export. |
| **DF-05** | `crates/attendance-face/src/index.rs` (`search_tiered`) | `search_tiered` had an `else if min_dist <= EXACT_THRESHOLD` branch that matched even if only 1 out of 20 enrolled frames matched (`match_ratio = 5% < 40%`), bypassing Python's `match_ratio >= 0.40` requirement (`attendance_v8.py` lines 4823–4860). | Fallback branch in `search_tiered` did not check `match_ratio >= 0.40` when `num_enrolled >= 8`. | Enforced `if match_ratio < 0.40 { ("REJECT", 0.0) }` for multi-pose profiles (`num_enrolled >= 8`) and filtered corrupted constant vectors (`[0.044194173; 512]`). |

## 2. Historical Repository & Commit Timeline

1. **`rust_deepFace/` Standalone Prototype**:
   - Created `src/mtcnn.rs`, `src/facenet512.rs`, `src/pipeline.rs`, `src/state.rs`, and `generate_onnx_models.py`.
   - `generate_onnx_models.py` constructed dummy ONNX graphs with random weights (`np.random.seed(42..45)`).
   - Included `rust_deepFace/test_images/` containing 23 real test images:
     - Angelina Jolie (`Jolie_1.jpg` .. `Jolie_6.png`, `face8.jpg`)
     - Albert Einstein (`Einstein_1.jpg`, `Einstein_2.jpeg`)
     - Osman Hadi (`Osman_Hadi_1.jpg`, `Osman_Hadi_2.jpg`, `Osman_Hadi_3.jpg`)
     - Brad Pitt (`pit.jpg`)
     - Multi-face image (`100.jpeg` — 2 faces)
     - Non-face edge cases (`Blank_Img.png`, `Noise_Img.png`)
2. **Migration into `crates/attendance-face` (Commits `00377e4` .. `2d123cd`)**:
   - `rust_deepFace/src/*.rs` was copied into `crates/attendance-face/src/`.
   - Because the synthetic random MTCNN models in `models/` failed to detect faces on real images, a 60% center-crop fallback was added in `crates/attendance-face/src/pipeline.rs` (`lines 87-111`).
   - Additionally, `main.rs` seeded 3 dummy users (`EMP001`, `EMP002`, `EMP003`) with constant vectors `vec![0.044194173f32; 512]` (`1 / sqrt(512)`).
3. **Forensic Recovery & Authentic Weight Conversion (Current Remediation)**:
   - Converted official DeepFace `facenet512_weights.h5` (Inception-ResNet-v1) and `facenet-pytorch` MTCNN (`pnet.pt`, `rnet.pt`, `onet.pt`) to ONNX opset 13 (`scripts/convert_authentic_onnx.py`).
   - Verified `tract-onnx` loads and executes all 4 authentic ONNX models in `1.73s` with AVX2/FMA acceleration.
   - Removed the 60% center-crop fallback, restored `enforce_detection=True`, fixed O-Net landmarks and `Min`-NMS, and purged constant dummy vectors.
