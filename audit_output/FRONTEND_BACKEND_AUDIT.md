# FRONTEND vs. BACKEND INTEGRATION AUDIT

> **Audit Scope:** Line-by-line cross-check of HTML DOM IDs in `crates/attendance-api/src/ui/kiosk_view.rs` (717 lines), JavaScript DOM queries and `fetch()` calls in `crates/attendance-api/src/ui/scripts.rs` (1,484 lines), and Axum routers in `crates/attendance-api/src/routes/*.rs`.
